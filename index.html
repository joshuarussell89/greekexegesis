Big idea

Install the Greek New Testament

All 27 books with full morphological parsing, from the MorphGNT edition of the SBL Greek New Testament. About 8 MB, fetched once and kept on this device.

The Greek is the SBLGNT with MorphGNT tagging; the Hebrew is the Westminster Leningrad Codex with Open Scriptures morphology. The Old Testament is four times the size and takes a few minutes.
Or open ⋯ and load the files yourself.

Building the diagram

Split / Join
Tap any word to break the line before it; the new line is indented one level. Tap the first word of a line and the break is undone — so the same tap both splits and rejoins. Dragging a line's grip up onto the line above also rejoins it.
Indent
Drag a line's grip sideways; it snaps to a 36 pt grid.
Float a word
Drag any single word out of the flow for fine placement.
Auto-split
Breaks at conjunctions, participles, infinitives and relatives — a first draft in one tap.

Annotating

Anchoring
Every mark attaches to its nearest word, so ink follows the text when you move it.
Line
Snaps to true horizontal or vertical within 8°.
Box
Drag corner to corner. Erasing its empty interior is ignored.
Eraser
Rubs out whatever it passes over — ink, lines, boxes, arrows, and the underline, box or symbol on a word. Lemma highlights are left alone, since those belong to every occurrence; clear those from the word inspector.
Line styles
Tapping Line opens a menu of weights. Thin, regular, dotted and double are ordinary strokes. Extra thick is different: it lays a section break across the page, opens a gap in the flow, and gives you a title to fill in. Tap the same boundary again to remove it.
Colour
Tap the floating puck to open the wheel; drag the hub to move it. 18 colours, shown as tints while the highlighter is active.

Finding and marking

Find
Search the parsing itself. Tap Imperative to light up every imperative in the passage; add Aorist to narrow it to aorist imperatives. Chips combine, and the box accepts a lemma or an English gloss. Accents are ignored, so λυπεω finds λυπέω.
Apply
Highlight, Underline or Box every match at once, in the wheel's current colour.
Mark
Underline a word, box it, or lay a symbol over it — ♥, 🩸, ✝, ★ and others. Symbols sit on the word, see-through like the highlighter. Tap a word to apply, tap again to remove. Marks attach to the word, so they move with it.
Hebrew
An Old Testament book is laid out right to left: lines begin at the right margin and each level of indent steps in from the right. Everything else behaves the same. The word inspector links to HALOT rather than BDAG, and to your Hebrew text rather than the Greek — both set under ⋯.
Chain
Tap a word and write a reference to link it to another part of this book — two rings and the reference, as on the worksheet. Tapping the rings in Move/Select takes you there.
Cross-ref
Drag a square round a quotation or allusion and write what it quotes — Isaiah 49:8. Tapping its label opens that passage in Accordance, in the English translation set under ⋯.

Finding a passage

Reference
Type it in the box at the top left: 2 Corinthians 1:12–2:4, Rom 8:1-17, 1 Jn 2, Phlm 4-7. Ranges may cross a chapter break, which chapters alone cannot. Abbreviations and 2 Cor style both work.
Its own page
Each range keeps its own diagram, ink and notes, so 1:12–2:4 and chapter 1 are separate pieces of work.

Load a full book

Drop GitHub's sblgnt-master.zip here for the whole New Testament — no need to unzip it. Individual -morphgnt.txt files work too, as many at once as you like. Loaded books are remembered; you only do this once.

Another tagged text? Drop a single .txt or .tsv file that isn't MorphGNT — a Septuagint dataset, for instance — and you'll be asked which column is which. Note that CATSS-derived LXX data carries its own conditions: you need to obtain it yourself and agree to their user declaration. Nothing is downloaded for you.
Hebrew. Drop OSIS .xml files from openscriptures/morphhb for the Old Testament — or use the buttons on the welcome page, which fetch both testaments for you. The Westminster Leningrad Codex text is public domain; its lemmas and morphology are © the Open Scriptures Hebrew Bible Project, CC BY 4.0.
Nothing loaded — the built-in passage is hand-parsed.

Sync between devices

Keeps your work the same on the iPad and the Mac through a private GitHub repository — not the public one your app is served from. Work done in both places is combined rather than overwritten. How do I set this up?
Off.
Once, on a computer:
1. At github.com/new make a repository called nous-work and set it to Private. Nothing else — no README needed.
2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
3. Give it a name, set the expiry as long as you're comfortable with, and under Repository access choose Only select repositories → nous-work.
4. Under Permissions → Repository permissions set Contents to Read and write. Leave everything else alone.
5. Generate it and copy the token — GitHub shows it once.

Then on each device: type the repository as yourname/nous-work, paste the token, and tick Turn it on. Do the Mac first and let it finish, then the iPad.

The token is kept on the device you typed it on and is sent only to GitHub. If you ever lose a device, delete the token on GitHub and it stops working. When it expires, Nous will tell you here and your work carries on being saved locally in the meantime.

Export

The outline turns each section title into a numbered heading, with the verse range and your notes beneath it. The image is exactly what you see: text, ink, boxes, arrows, section breaks and marks. Printing uses the iPad's own share sheet, where "Save to Files" produces a PDF.
